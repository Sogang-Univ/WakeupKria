# WakeupKria
 
음성으로 디바이스를 활성화하고 제스처로 명령을 내린다
 
## 프로젝트 소개
 
**카메라를 만지지 않고 카메라를 조작한다.**
 
촬영 중인 카메라의 설정을 바꾸려면 보통 기기에 손을 대야 한다. 그 순간 화면이 흔들리고,
피사체에서 눈을 떼야 하고, 장갑을 끼었거나 손이 젖었다면 아예 불가능하다.
WakeupKria는 그 조작을 **음성과 손짓**으로 옮긴다.
 
카메라 두 대가 서로 다른 역할을 맡는다.
 
| | 역할 |
|---|---|
| **카메라 1** | 사용자의 손을 읽는 **입력 장치** |
| **카메라 2** | 명령을 받아 제어되는 **대상** |
 
동작 흐름은 이렇다.
 
```
[마이크] 웨이크워드 검출
              ↓
[카메라 1] 제스처 대기 → 인식
              ↓
[카메라 2] 확대 / 축소 · AI 기능 활성화 / 비활성화
```
 
평상시에는 카메라 1이 제스처를 인식하지 않는다. 웨이크워드를 부른 뒤에만 명령을 받는다.
음성은 "지금부터 명령하겠다"는 신호에만 쓰고, 실제 명령은 손이 전달한다.
마이크를 계속 열어두지 않아도 되고, 소음 환경에서도 명령이 왜곡되지 않는다.
 
전체 연산은 **AMD Kria KV260** 위에서 끝난다. 클라우드로 나가지 않는다.
무거운 손 검출은 FPGA의 DPU가 맡고, 가벼운 시퀀스 분류와 음성 검출은 Cortex-A53이 처리한다.

## 프로젝트 목표
 
**단일 DPU 코어 위에 팀 전체의 AI 모델을 공존시킨다.**
 
제스처 인식뿐 아니라 카메라 2에서 동작할 기능도 별도의 AI 모델을 필요로 한다.


### 모델 제출 요건
 
각 모델은 다음을 만족해야 통합 대상이 된다.
 
1. SiLU 등 DPU 미지원 연산을 지원 연산으로 교체
2. `vai_q_pytorch` 양자화 → `vai_c_xir` 컴파일 통과
3. **컴파일 결과가 단일 DPU 서브그래프**일 것
4. 프레임 예산 내 DPU 실행 시간 측정치 첨부
